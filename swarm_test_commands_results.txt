## Test 2: FusionNet vs Fixed CI Methods

### Commands:
```bash
# Collect fusion training data
python swarm_target_tracking.py \
  --exp default_3_random_0 \
  --use_height_tf \
  --collect_fusion \
  --out outputs_swarm

# Train FusionNet
python -m swarm_ml.train_fusionnet_cli \
  --snaps outputs_swarm/default_3_random_0_ifo003/fusion_snaps.jsonl.gz \
  --out models/fusionnet_default_3_random_0 \
  --epochs 20 --lr 1e-3 --batch_size 64 --seed 0

# Test CI methods
python swarm_target_tracking.py \
  --exp default_3_random_0 --use_height_tf \
  --ci_method uniform \
  --out outputs_swarm/ci_uniform

python swarm_target_tracking.py \
  --exp default_3_random_0 --use_height_tf \
  --ci_method grid --ci_objective logdet --ci_grid 0.1 \
  --out outputs_swarm/ci_grid

python swarm_target_tracking.py \
  --exp default_3_random_0 --use_height_tf \
  --ci_method learned --fusionnet_dir models/fusionnet_default_3_random_0 \
  --out outputs_swarm/ci_learned
```

### Results:
| CI Method | RMSE_3D | NEES | Performance |
|-----------|---------|------|-------------|
| Uniform CI | 0.751m | 10.564 | Good baseline |
| Grid CI | 0.769m | 13.701 | Standard |
| **Learned CI** | **0.746m** | **9.068** | **Best centralized** |
